What it is

RAW-SNES connects a physical Super Nintendo, an FXPak Pro and RetroAchievements. Achievements trigger from the actual console state, read from the console's work RAM while you play. The game's ROM is never changed.

How it works

The FPGA on the FXPak Pro sits on the cartridge bus. Every time the console's CPU writes to its work RAM, the FPGA writes the same value into a mirror of its own. The program on your PC reads that mirror over USB and evaluates the achievement conditions as the game runs. For games without an enhancement chip, nothing runs on the console at all.

Work RAM, mirrored live

All 128 KB of work RAM are copied as they are written, by the cartridge itself. The console does no extra work for it, so games run at full speed.

The game names itself

The program reads the ROM from the cartridge over USB, identifies it and loads its RetroAchievements set. In normal use there is nothing to select and no folder to point at.

Enhancement chips

For SA-1, Super FX, Cx4 and S-DD1 games the cartridge keeps no copy of work RAM. There the console copies the values RAW-SNES needs once per frame, through the cartridge's in-game hook. Tested on hardware with all four. Because of a limit of the cartridge's original firmware, some of these games are only partly supported: not every achievement is monitored at once. The others are only monitored once unlocks free up room, and anything you achieve for them before that does not count. The program shows this in red. Full support is in the master version (see below). DSP games work like games without a chip.

Hardcore mode

Not available yet

RetroAchievements only counts Hardcore unlocks from clients it has approved, and a client has to be publicly available for at least six months before it can be considered. Until then, every unlock is recorded as Softcore.

Known limits

Games with an enhancement chip need the in-game hook turned on in the cartridge's settings. Because of a limit of the cartridge's original firmware, some of them are only partly supported; the program shows this in red. Full support is in the master version (see below). DSP games need the DSP firmware files in the cartridge's sd2snes folder; without them the game hangs, with or without RAW-SNES. The SD2SNES runs the same firmware and should work, but has not been tested.

The master version

The master version is finished and runs on real hardware. It adds save states with sound and a menu right on the console, and full support for every enhancement chip game. Unresolved licensing questions currently keep it from being released. To be continued.

save state path — the music is part of the state

Save states that keep their sound

RAW-SNES saves and loads the game together with its sound, on a real Super Nintendo. Load a state and the music plays on exactly where it was, right on the console, without a PC.

Four slots, each with the date and time it was saved. Flip through them with left and right and see which slot you are on before you save or load.

A menu on the console

Start + R opens a menu on the console itself: continue, save, load or exit. The selected slot is always on screen, and you pick it with left and right. Every save is stamped with date and time, so you see at a glance what is in each slot. The state goes to the SD card, no PC involved, and the music carries on where it was.

Every achievement on enhancement chip games

Full coverage for SA-1, Super FX, Cx4 and S-DD1 games: all achievements at once, every frame, with nothing running on the console.

RAW-SNES is free to use. The source is public to read and audit, but it is not open source — see the license. RAW-SNES talks to the FXPak Pro over its own USB interface and is not affiliated with the makers of the cartridge or its firmware.

There are counterparts for the NES, the Mega Drive and the Saturn too: RAW-NES, MEGA-RAW and RAW-TURN.
